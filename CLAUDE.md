# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Branding

The in-game currency/brand name is always spelled **LOK** (all capitals) in any
user-facing text — UI copy, button labels, messages, docs. Never write it as "Lok"
or "lock".

This does not apply to TypeScript/React identifiers that happen to start with
those letters as normal mixed-case naming (e.g. `LokDexPanel`, `LokPetDefinition`,
`lokRuntime`) — those are fine as they are.
